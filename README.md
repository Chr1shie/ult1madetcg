# ult1madetcg.com

Öffentliche Projektseite von **Ult1made TCG** — Sammlungs-Tracker für 15
Trading-Card-Spiele (iOS/Android) mit optionalem eigenem Sync-Server.

Diese Seite wird über GitHub Pages ausgeliefert. Sie besteht aus genau
zwei eigenständigen Dateien ohne externe Abhängigkeiten:

- `index.html` — die Homepage
- `anleitung.html` — das komplette zweisprachige Handbuch

**Nicht direkt hier bearbeiten.** Beide Dateien werden im (privaten)
App-Repository unter `docs/` gepflegt und von dort mit
`tools/publish-homepage.sh` hierher übertragen.
